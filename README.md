# Email Forensics Tools

### Email Forensics Tools Collection

A list of tools used to collect, read and search email evidence. Prices were checked on 17 October 2026 and can change, so confirm on the vendor site. We are the team behind MailXaminer at SysTools, and we mark it in the list. Missing a tool? Open an issue.

[#free](#free) | [#paid](#paid) | [#license](#license)

## Free

- **Autopsy**: Open source digital forensics platform with a graphical interface. It has an email parser module and keyword search for mail files.
  * Website: <https://www.autopsy.com/>

- **bulk_extractor**: Scans disk images, files and directories and pulls out structured data like email addresses without parsing the file system.
  * Website: <https://github.com/simsong/bulk_extractor>

- **CAINE**: Free and open source Linux live distribution for digital forensics, built in Italy on Ubuntu.
  * Website: <https://www.caine-live.net/>

- **emlAnalyzer**: Command line tool that reads EML files. It shows headers and MIME structure and pulls out attachments, links and tracking pixels.
  * Website: <https://github.com/wahlflo/eml_analyzer>

- **ExifTool**: Reads and writes metadata in image, audio, video and PDF files. It helps with checking email attachments.
  * Website: <https://exiftool.org/>

- **FTK Imager**: Previews and images drives without changing the original and creates hash values.
  * Website: <https://www.exterro.com/digital-forensics-software/ftk-imager>

- **Google Admin Toolbox Messageheader**: Web tool that reads a pasted email header. It shows delivery delays and the approximate source.
  * Website: <https://toolbox.googleapps.com/apps/messageheader/>

- **libpff**: Library and tools for reading the PST and OST files that Outlook uses. It is in alpha status and uses the LGPL license.
  * Website: <https://github.com/libyal/libpff>

- **Plaso (log2timeline)**: Python based engine that builds super timelines for forensic analysis. It uses the Apache-2.0 license.
  * Website: <https://github.com/log2timeline/plaso>

- **readpst (libpst)**: Converts PST files to MBOX or separate EML files.
  * Website: <https://www.five-ten-sg.com/libpst/>

- **SIFT Workstation**: Free and open source toolkit for forensics and incident response, from SANS.
  * Website: <https://www.sans.org/tools/sift-workstation/>

- **The Sleuth Kit**: Library and command line tools for disk and file system forensics. Autopsy is built on top of it.
  * Website: <https://www.sleuthkit.org/>

- **Wireshark**: Network protocol analyzer that captures and examines network traffic. It is released under the GNU General Public License version 2.
  * Website: <https://www.wireshark.org/>

## Paid

- **Aid4Mail**: Email collection and conversion software for forensics, eDiscovery and migration, made by Fookes Software. A free trial is available.
  * Price: Converter 299, Investigator 999 and Enterprise 4,999 billed annually, with monthly plans also listed. Prices exclude VAT or GST.
  * Website: <https://www.aid4mail.com/pricing>

- **Belkasoft X**: Computer, mobile, drone, car and cloud forensics in one tool.
  * Price: Corporate edition from €7,499 per year as listed on G2. Government and law enforcement pricing is on request.
  * Website: <https://belkasoft.com/x>

- **Cyber Triage**: Digital forensics software that automates evidence collection and analysis to help investigators find threats faster.
  * Price: Standard Pro $3,500 per year for one investigator. Team and Enterprise tiers are on request.
  * Website: <https://www.cybertriage.com/pricing/>

- **EnCase Forensic**: Forensic suite from OpenText used to recover evidence from seized drives.
  * Price: On request
  * Website: <https://www.opentext.com/products/encase-forensic>

- **Forensic Email Collector**: Software from Metaspike that connects to cloud email providers and preserves email evidence.
  * Price: $1,699
  * Website: <https://www.metaspike.com/forensic-email-collector/>

- **FTK (Forensic Toolkit)**: Computer forensics software from Exterro. It scans drives, indexes the data and can find deleted emails.
  * Price: On request
  * Website: <https://www.exterro.com/digital-forensics-software/forensic-toolkit>

- **Intella**: Search and review software for email and other evidence, built for investigations and eDiscovery. A free trial is available.
  * Price: On request
  * Website: <https://www.vound-software.com/>

- **Magnet AXIOM**: One case file for mobile, computer and cloud evidence. It comes in Essentials, Advanced and Premier packages.

- **MailXaminer** (by the maintainers of this list): Windows software for email evidence. It offers general, fuzzy, wildcard, regular expression, proximity and stem search, plus link, timeline and word cloud views.

- **Nuix**: Investigation and eDiscovery software that makes large volumes of unstructured data searchable and ready for analysis.
  * Price: On request
  * Website: <https://www.nuix.com/>

- **OSForensics**: Forensic software from PassMark. A trial version can be downloaded without a contact form.
  * Price: Subscription $95 per month or $945 per year. Perpetual license $1,680 with 12 months of support and updates.
  * Website: <https://www.osforensics.com/>

- **Oxygen Forensic Detective**: Forensic software built to extract, decode and analyze data. It uses a perpetual license, with network tiers of 5, 10, 20 or 50 concurrent connections.
  * Price: On request
  * Website: <https://www.oxygenforensics.com/en/products/oxygen-forensic-detective/>

- **Relativity**: eDiscovery platform that carries a case from data intake through review to production, with AI assisted review.
  * Price: On request
  * Website: <https://www.relativity.com/>

- **X-Ways Forensics**: Forensic software for disk imaging and analysis. Updates are included for at least 12 months.
  * Price: On request
  * Website: <https://www.x-ways.net/forensics/>
